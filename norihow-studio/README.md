# NORIHOW STUDIO — AI 팀원 대시보드

유아교사 겸 콘텐츠 크리에이터 미니님을 위한 1인 회사 AI 허브 웹앱입니다.
7명의 AI 팀원이 콘텐츠·개발·커리어 업무를 도와드립니다.

## 시작하기

### 1. API 키 설정

`index.html` 파일을 열고 최상단 스크립트에서:

```javascript
let API_KEY = ''; // ← 여기에 Anthropic API 키 입력
```

또는 앱을 열면 상단에 노란 배너가 표시되며, 입력창에 API 키를 직접 입력할 수 있습니다.

> API 키는 [Anthropic Console](https://console.anthropic.com/)에서 발급받으세요.  
> `sk-ant-...` 형식의 키를 사용합니다.

### 2. 실행

`norihow-studio/index.html` 파일을 브라우저에서 바로 열면 됩니다.  
별도 서버 설치 없이 단일 파일로 동작합니다.

## 팀원 소개

| 이름 | 팀 | 전문 분야 |
|------|-----|----------|
| 리나 | 📱 콘텐츠팀 | 인스타 카드뉴스·릴스·캡션·해시태그 |
| 하나 | 📱 콘텐츠팀 | 마케팅 분석·계정 성장 전략 |
| 아라 | 📱 콘텐츠팀 | 비주얼 디렉션·색감·레이아웃 |
| 코코 | 🌱 개발팀 | 교육 앱 HTML/CSS/JS 개발 |
| 나무 | 🌱 개발팀 | 누리과정·레지오 에밀리아·발달심리 |
| 솔 | 💼 커리어팀 | 자소서·면접 준비·취업 전략 |
| 도도 | 💼 커리어팀 | 퍼스널 브랜딩·커리어 로드맵 |

## 주요 기능

- **홈** — AI 브리핑 자동 생성, 팀원별 오늘의 제안, 부서별 필터
- **지시창** — 팀원 선택 후 작업 지시, 빠른 지시 버튼, 스트리밍 결과
- **프로젝트 보드** — 칸반(아이디어→작업중→검토→완료), 드래그앤드롭
- **주간 리포트** — 솔이 작성하는 이번 주 정리 + 다음 주 방향 제안
